# Modern-feel spec — the "alive" layer

## Unit motion (biggest gap)
- Turn-to-face before moving; no instant vector snap.
- Acceleration + braking curves, not constant velocity.
- Bank/lean on turn for vehicles. Idle bob for infantry.
- Death animation (2-3 variants) + wreck that persists ~10s.
- Recoil on fire; turret lead on target.

## Combat feedback
- Muzzle flash, tracer/arc, impact spark + decal, explosion with smoke.
- Screen shake scaled to damage. Brief hit-stop on big hits.
- Damage numbers or health bars that fade in on hit.
- Death sound, not just a silent despawn.

## Control (StarCraft II standard)
- Box select, shift-add, double-click select-all-type, control groups 1-9.
- Attack-move, shift-queued orders, waypoint display.
- Right-click contextual, rally points with visual, minimap pings.
- Zoom-to-cursor, edge scroll toggle (Options already has some of this).

## Audio density
- Footprints, engine loops, idle chatter/barks, build clangs.
- Ambient bed that shifts by tier. Music already exists — keep it.

## Readability
- Health bars, selection rings, unit-type icons in build menu.
- Alert/ping system for "under attack." (partially exists — surface it)
